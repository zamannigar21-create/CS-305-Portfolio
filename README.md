
## Artemis Financial Secure Software Project

### Client Summary
Artemis Financial is a consulting company that provides financial planning services, including savings, retirement, investments, and insurance. The company wanted to improve the security of its web application by protecting sensitive financial data and ensuring secure communication.

### What I Did Well & Importance of Security
I identified missing security features and implemented solutions such as HTTPS and SHA-256 hashing. Coding securely is important because it protects sensitive data from being exposed or altered. Software security helps prevent data breaches and builds customer trust.

### Challenges
One challenge was running the OWASP dependency-check tool, which failed due to external database download issues. However, it helped me understand how vulnerability scanning tools work.

### Increasing Security Layers
I increased security by implementing SHA-256 hashing for data verification and enabling HTTPS using a self-signed certificate. In the future, I would use tools like OWASP Dependency-Check and static analysis tools to assess vulnerabilities.

### Ensuring Functionality & Security
I tested the application by running the server and accessing the "/hash" endpoint. After refactoring, I verified that the application worked correctly and did not introduce new vulnerabilities.

### Tools & Resources Used
- Eclipse IDE  
- Java Keytool  
- Spring Boot  
- OWASP Dependency-Check  

### What I Would Show Employers
I would show this secure software project and report as an example of my ability to identify vulnerabilities, apply security solutions, and develop secure applications.
